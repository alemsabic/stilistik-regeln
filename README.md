# stilistik.org - Regeln

Die Stilistik für professionelles Deutsch. Offen, lebendig, präskriptiv.

## Struktur

- Markdown-Einträge für Stilregeln

## Workflow

1. Einträge lokal schreiben in diesem Repository
2. Push to main → GitHub Actions
3. Automatischer Sync zu [stilistik-site](https://github.com/alemsabic/stilistik-site)
4. Cloudflare Pages build → Live auf [stilistik.org](https://stilistik.org)

## Deployment

- **Display Repo:** [alemsabic/stilistik-site](https://github.com/alemsabic/stilistik-site)
- **Live Site:** [stilistik.org](https://stilistik.org)
- **Engine:** Quartz v5
